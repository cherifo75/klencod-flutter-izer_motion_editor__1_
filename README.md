# Izer Motion Editor

## الخطوات داخل Klencode

أنشئ مشروع Flutter جديدًا باسم `islamic_daily_publisher`، ثم استبدل ملف `lib/main.dart` بهذا الملف، واستبدل `pubspec.yaml` بالملف الموجود هنا.

بعد ذلك شغّل:

```bash
flutter pub get
flutter build apk --debug
```

ملف التطبيق:

```text
build/app/outputs/flutter-apk/app-debug.apk
```

النسخة الأولى هي واجهة محرر موشن أصلية: معاينة، طبقات، Timeline، نص، تحكم بالحجم والدوران والشفافية وKeyframes. استيراد الوسائط والتصدير الحقيقي سيضافان في المرحلة التالية.
